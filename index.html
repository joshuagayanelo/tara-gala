Your data

Add a leg for every drive, ferry, or major transfer. Arrival times and totals are calculated for you. Changes are saved in this browser only, so save a backup before switching devices.

Google Maps

Paste a Google Maps API key to get place suggestions, pin locations on a map, and automatic distance and driving time. In Google Cloud, enable Maps JavaScript API, Places API (New) and Routes API (add Geocoding API too if you want pinned and current locations shown as addresses), and limit the key to those APIs and your website address. A key limited to a website address won't work when this file is opened straight from your computer, so host the page first.
